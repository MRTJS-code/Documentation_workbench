# DPDISSIS Enhancements

| Category | Current behavior | Risk | Suggestion | Effort | Notes |
|---|---|---|---|---|---|
| Naming | Local project is `Job ODS NZ Deputy`; framework config uses `Job ODS NZ SEC Deputy`; user-facing name is `DPDISSIS`. | Deployment/config confusion. | Standardize project naming or add a mapping note in deployment scripts. | Low | Evidence: `.dtproj`, setup SQL, user request. |
| Framework status | Setup SQL sets jobs `8005`/`8006` to `PAUSED`; framework docs list `READY`, `WAITING`, `IN PROGRESS`, `FAILED`, `ERROR`, `DISABLE`. | Operators may not know whether `PAUSED` is supported or custom. | Document accepted statuses in current framework DB or align script with documented statuses. | Low | Do not change without confirming live framework behavior. |
| Event flow | EDA event tables/proc exist but packages do not reference them. | Event creation/completion cannot be traced from this repo. | Add package integration or document the external event producer. | Medium | Objects: `eda.ETL_EVENT`, `eda.UPDATE_EVENT_STATUS`. |
| Retry variables | Requested `ERR_MAX_FAIL` and `ERR_PRIOR_FAIL_COUNT` are not found. | Retry behavior may be implicit and hard to operate. | Locate framework package/source or expose retry variables in docs/setup SQL. | Medium | Framework docs cover thresholds through config fields. |
| QA execution | Package SQL contains commented `EXEC qa.ProcessQualityIssues` statements. | QA captures may not be persisted/closed as intended if comments are active in runtime SQL. | Confirm whether comments are deliberate; enable or remove dead SQL. | Medium | Evidence in `5 Quality Assurance Builds.dtsx`. |
| Package metadata | Several package object names are `Package1`. | SSIS logs are harder to read. | Rename package object names to match file names. | Low | Does not require data logic changes. |
| Fixed rebuild date | Setup SQL value and `Project.params` default differ. | Local runs can rebuild a different range than framework runs. | Document precedence and keep default aligned with deployment script where possible. | Low | `CTL_JOB_CONFIG_VARIABLES` should override under framework. |
| Empty containers | `5 Aggregate Tables`, `6 Conformed Tables`, `7 Semantic Layer`, and `9 DW Pre Tasks` have no child tasks. | Operators may expect work that does not happen. | Add comments/documentation or remove empty containers if obsolete. | Low | Keep if project template requires them. |
| Object reference mismatch | Package text references `lookup.DEP_ClientTiers`; schema contains `lookup.DEP_ClientTier.sql`. | Runtime failure if plural object is not present in target DB. | Verify live object name and update package/schema as needed. | Medium | Do not infer columns or object existence from naming. |
| Deployment evidence | Environment definitions are not present in repo. | Re-deployments depend on external SSISDB setup. | Add environment creation and parameter binding scripts. | Medium | Deployment doc says SSISDB environment assignment is required. |
| SQL maintainability | Large inline SQL blocks live inside DTSX. | Harder review, testing, and source diffing. | Move stable transformation logic to stored procedures or checked-in SQL files where appropriate. | High | Best for dimension/fact and QA SQL first. |
| Validation | No automated validation scripts found for package/object mapping. | Docs and packages can drift. | Add a lightweight metadata extraction script that emits package-task-object inventory. | Medium | Keep generated output out of production deploy path. |
